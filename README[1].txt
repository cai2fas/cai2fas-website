# cai2fas website

Open index.html in a browser to preview the site.

The site includes:
- Professional dark creator design
- YouTube, Twitch, TikTok and Discord links
- Video embed
- Clips section
- Subscriber / video / view stats area
- Responsive mobile layout

For truly live YouTube stats, the JavaScript includes optional YouTube Data API support. You would need a YouTube Data API key and your channel ID, then put them into API_KEY and CHANNEL_ID in index.html. YouTube documents channel statistics here:
https://developers.google.com/youtube/v3/docs/channels
